**Documentation for the Hatsuboshi API & the Hatsuboshi App Types Package.**

- The Hatsuboshi API documentation is rendered with [Redoc](https://redocly.com/) using an [OpenAPI 3.1 specification](https://www.openapis.org/).
  - Homepage ([production](https://docs.hatsuboshi.app/api/)) ([development](https://docs.hatsuboshi.app/api-dev/))
  - OpenAPI specification `swagger.json` ([production](https://docs.hatsuboshi.app/api/v1/swagger.json)) ([development](https://docs.hatsuboshi.app/api-dev/v1/swagger.json))

- The Types Package reference can be accessed at https://docs.hatsuboshi.app/types/latest. These static HTML files are auto-generated by [TypeDoc](https://typedoc.org/).
  - Homepage ([latest](https://docs.hatsuboshi.app/types/latest/))
  - Links manifest `links.json` ([latest](https://docs.hatsuboshi.app/types/latest/links.json))

## Technical Details

This repository hosts static artifacts generated by the `hatsuboshi-app/backend` & the `hatsuboshi-app/types` packages and deploys them to the web on [Vercel](https://vercel.com/). Additionally, extra styling used on the landing page & the version switcher for the API docs is done with [Tailwind CSS](https://tailwindcss.com/).

The files are served statically with the exception of `/public/styles.css`, which needs to be built using Tailwind:
```bash
$ npm run build
```

## Deployment

This repository uses [GitHub Actions](https://github.com/features/actions) to automatically run CI/CD pipelines for deployment.

- The `main` branch automatically deploys to the production environment ([`https://docs.hatsuboshi.app`](https://hatsuboshi.app)).
