    Class PItem

    A P-Item / produce item (Pアイテム).

    These are items that can be obtained throughout the duration of a produce run that provide effects to both the produce run itself, as well as during lesson/audition gameplay sectors (e.g. "あの日の約束" / "The promise of that day", "ピッグドリーム貯金箱" / "Piggybank of Big Dreams", "「Pっち」" / "'P-cchi'", etc.).

    Tip

    See PItemFilterOptions for the list of filtering options.

    See IPItem for the list of fields that can be used for sorting.
