    Class PIdol

    A produce idol / P-Idol (プロデュースアイドル / Pアイドル).

    These are units available for use in produce scenarios. For example, "極光" / "Kyokkou", "世界一可愛い私" / "Sekaiichi Kawaii Watashi", "サンフェーデッド" / "SUNFADED" are produce idol units of their respective characters.

    Tip

    See PIdolFilterOptions for the list of filtering options.

    See IPIdol for the list of fields that can be used for sorting.
